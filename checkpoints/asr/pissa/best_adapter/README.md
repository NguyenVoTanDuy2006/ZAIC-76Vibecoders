# Qwen3-ASR PiSSA adapter

This is the epoch 3 adapter selected by validation latest normalized PhoBERT F1.
It was converted from PiSSA to standard LoRA rank 16 and must be loaded on
`Qwen/Qwen3-ASR-1.7B-hf` at revision
`bcd2b5b7f32b480ab5790554cfa8347f246a14f3`.

See [the run guide](../README.md) for training, inference, metrics and artifact
provenance. The pretrained base weights are distributed separately by Qwen.
